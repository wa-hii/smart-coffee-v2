# Migrasi RF500 + Take Data dari Pi5 pertama ke Pi5 kedua (COM5)

**Tanggal:** 23 November 2026 WIB.
**Hasil:** kode dan model terpasang, preflight PASS,
autostart cron terdaftar, listener `READY` / idle. **Bukan**
validasi AI Test atau Take Data fisik E2E.

## Lingkup dan identitas

- Sumber: `enose-v3@enose-pi5`, model `final_model.joblib`
  dan modul `rf500_pi_persistent_listener.py`,
  `pi_labeled_take_data.py`, `rf30_pi_result_bridge.py`,
  `roast_rf30_pi_inference.py` dan replay.
- Tujuan: `raspi5@raspberrypi`, Tailscale `100.94.161.96`.
  Akses melalui kunci SSH lokal terotorisasi; tidak ada kunci
  privat/password yang disalin ke repository.
- USB board: Windows COM5 FT232RL `A10KMM3SA`, identitas udev
  Pi `0403:6001`, serial `A10KMM3S`, symlink
  `/dev/serial/by-id/usb-FTDI_FT232R_USB_UART_A10KMM3S-if00-port0`
  → `/dev/ttyUSB0`; grup pengguna mencakup `plugdev`.
- Kondisi daya Pi: `vcgencmd get_throttled` = `throttled=0x0`.
  Pi sumber tetap menjalankan listener USB serial lain
  `A10KMZQJ` (PID saat inspeksi 882).

## Bukti kesiapan dan batas QA

1. `installer.py --check`: `COM5_PI2_READ_ONLY_PREFLIGHT_PASS`;
   bridge dan model `PERSISTENT_BRIDGE_AND_MODEL_READ_ONLY_PREFLIGHT_PASS`.
2. `installer.py --install`:
   `COM5_RF500_AUTOSTART_REGISTERED_AND_VERIFIED`
   (user `cron @reboot`, bukan systemd).
3. `installer.py --start`:
   `COM5_PI2_PERSISTENT_LISTENER_READY pid 2114`.
   Pemeriksaan berikutnya: proses listener Python PID 2123
   memiliki argumen USB `A10KMM3S` dan model asli.
4. `supervisor.log` mencatat
   `TAKE_DATA_RECOVERY_STARTUP`, `RF500_PERSISTENT_READY`,
   heartbeat `rx_bytes_total=993`, `active_capture=false`,
   `take_data_active=false`, `successful_sessions=0`.
   Tidak ada ADC selama sesi idle; non-JSON boot banner normal.
5. Tidak mengirim perintah akuisisi, mengaktifkan solenoid,
   kalibrasi, flashing atau mengubah Nextion. Kondisi visual
   HMI menu adalah laporan operator, bukan inspeksi video.

**Belum dilakukan:** uji reboot dan recovery otomatis,
uji AI Test fisik 30 siklus (900 frame), respons RF500→MCU
dan tampilan hasil Nextion, Take Data CSV fisik serta
kelengkapan metadata sampel. Sensor/kalibrasi perlu
dipastikan sebelum menguji dan akurasi lintas alat tidak
boleh diklaim hanya berdasarkan status listener READY.
