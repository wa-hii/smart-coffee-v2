# Receiver v9 — continuous capture through malformed frames

## Tujuan dan batas mutu

Pengguna melaporkan ALAT_3 `L-CAT_B63` langsung dihentikan pada 128 baris
setelah event `SERIAL FRAME REJECTED malformed_json` sepanjang 257 byte;
ingin perangkat tetap merekam hingga 900 sampel. Perubahan v9 **tidak
mengabaikan integritas data**: sensor rusak dilewati sementara proses tetap
merekam seluruh 30 siklus, tetapi CSV final hanya ketika tepat 900 sampel
valid melewati validator. Data kurang lengkap dipertahankan tanpa overwrite
di `incomplete`, beserta sidecar kualitas `.quality.json`.

## Detail implementasi

- `--salvage-on-frame-error` pada supervisor multi-device dan receiver
  standalone; BAT 3 perangkat mengaktifkannya secara eksplisit.
- Satu frame JSON corrupt, invalid sensor payload, atau duplicate
  `(cycle, phase, sample_idx)` tidak menghentikan perekaman berikutnya.
  Sampel out-of-order/indeks di luar batas juga dilewati.
- Metadata korup, USB disconnected, timeout panjang, atau overlapping
  session tetap fatal untuk mencegah kontaminasi data.
- `ACQ_COMPLETE` perlu 30 siklus dan `total_samples==900` dari firmware.
  Validator 30 siklus dan 900 sensor valid harus PASS sebelum CSV final.
- Jika gagal, CSV tetap `incomplete`; sidecar menerangkan jumlah sampel
  sensor yang diterima, selisih menuju 900, hitungan error dan ID alat.
- Framer USB `read(256)` telah diverifikasi menampung potongan JSON
  >256 byte tanpa menutup frame prematur. Jadi frame sepanjang 257 byte
  dengan newline di tengah JSON bukan disebabkan otomatis oleh nilai
  `chunk_size=256`; penyebab transport fisik masih perlu audit.

## Offline QA

- `test_salvage_multi_receiver.py`: PASS: 1 malformed event pengganti satu
  sampel + satu duplikat, lanjut hingga akhir 30 siklus, 899 baris valid
  tetap di `incomplete`; sesi kedua 900 sensor valid + duplicate menghasilkan
  CSV final yang lulus validator dan laporan QA sidecar.
- `test_multi_device_receiver.py`: PASS: tiga worker paralel dua sesi tiap
  perangkat tetap sesuai perilaku ketat lama.
- `test_serial_frame_diagnostics.py`: PASS: frame JSON terfragmentasi
  di 256 byte, malformed 272-byte, invalid UTF-8, oversized.
- `test_acquisition_integrity.py`, `test_usb_autodetect.py`,
  `test_take30_contract.py`, `test_receiver_host_instance_lock.py`: PASS.
- ZIP portable v9 extraction/preflight: PASS.

**Batas bukti:** belum ada koneksi ke laptop Probook atau USB COM5/6/7;
tidak ada firmware atau hardware yang di-flash/di-reset. Mode salvage
belum menjamin 900 sampel sahih jika frame benar-benar hilang.
