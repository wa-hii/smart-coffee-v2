C hanya dievaluasi pada pemenang masing-masing durasi. `recordings.csv` adalah provenance, `folds.csv` split, `cv_scores.csv` seluruh konfigurasi, `duration_comparison.csv` hasil pilihan, `diagnostic_c_predictions.csv` prediksi C.

## Gate sebelum implementasi kandidat firmware dan deployment

Gagal generalisasi pada C dan replay fisik; jangan mengganti timer, model, atau release hardware sekarang. Target 5 menit tidak diubah. Perlu data lintas alat yang seimbang: usulan awal 5 pengulangan per roast per alat, origin dan massa dikontrol (30 rekaman x 900 sampel untuk satu origin, simpan device ID, specimen ID, batch, sesi, suhu/RH, warm-up, kondisi chamber). Pisahkan kelompok spesimen fisik untuk holdout prospektif yang tidak digunakan dalam pemilihan/normalisasi. Jika memungkinkan beberapa origin tambahan dan hari terpisah. 5 pengulangan bukan 5 spesimen independen bila menggunakan kopi yang sama. Rekomendasi gate awal (bukan angka yang sudah disetujui): balanced accuracy >=80%, recall tiap kelas >=70% pada holdout prospektif, laporkan per alat dan interval ketidakpastian; jangan klaim produksi bila sampel kecil/imbalanced. Model kandidat berikutnya dapat menguji baseline-relative dan domain adaptation yang dipelajari dari training saja. Kebutuhan data tidak membenarkan kalibrasi fisik tanpa SOP.

## Kontrak AI10–TAKE30 yang diusulkan (belum diimplementasikan)

1. Build profile terpisah dari `mega2560_waveform_rf30` dan build ID berbeda untuk fail-closed compatibility; Take Data 30 dan AI 10. Uji exact cycle, progress/ETA, pause/resume/cancel, gating actuator dan sample count. Jangan mengubah pin atau timing phase.
2. FW_HELLO harus membedakan ai_cycles_total=10 dan data_cycles_total=30. ACQ_START per mode memuat expected count benar. Host dan MCU harus menolak AI completion 299/301/900, token mismatch, stale result, wrong build, incomplete. Tetapkan versi reply gate yang eksplisit, jangan gunakan protokol RF30 lama dengan semantics berbeda.
3. LabeledTakeRecorder tetap menerima 900; listener baru harus memisahkan AI10 300 dari Take Data 900, enforce model schema/hash, parser/API dan regression tests, no data overwrite. Candidate model dipilih setelah validasi ilmiah, bukan hasil benchmark ini.
4. V7 geometry dan component IDs tetap; ETA 05:00 hanya AI Test, 15:00 untuk Take Data. Uji simulator dan physical upload terpisah dengan izin operator. Firmware/host/HMI tidak dibangun/dipromosikan sebelum gate ilmiah sesuai rekomendasi awal.
